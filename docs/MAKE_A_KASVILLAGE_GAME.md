# Make a KasVillage game

Starter template: [kv_game_template.html](kv_game_template.html)

## 1. One file

Your whole game is ONE .html file: HTML, CSS and JavaScript inside it. No other files, no links to other sites.

## 2. Draw your art in code

Use <canvas>, SVG or CSS shapes. Pictures (<img>, pasted image data, photos) are not allowed. Every image in KasVillage is generated, so nothing harmful can be uploaded.

## 3. No internet

Games run offline inside the wallet. No fetch / XMLHttpRequest / outside scripts. Save progress with localStorage.

## 4. Clean text

No adult content, gambling, weapons or drug sales, scams, slurs, or anything asking for wallet keys or phrases. The wallet checks every word before upload.

## 5. Name it

Set a <title>. "Moo Catch" becomes the id moo-catch automatically.

## 6. Publish

Workspace → DApps → PUBLISH YOUR GAME. Pick the file (or paste it / give a link). The wallet checks it, you TEST RUN it in the real player, then PUBLISH & LIST.

## 7. Cost

About 0.2 KAS per chunk of your game, parked in your own addresses (reclaimable), plus ~1 KAS to list it. The exact amount shows before you pay.

## 8. Keep it fresh

The chain keeps data about 30 hours. Players who installed it keep it forever; for NEW players, refresh with PUBLISH & LIST before the clock on your row runs out.

## 9. Extra boards

First board free. Sell more outside the app (Contact dev), then deliver with SEND BOARD. Your game reads window.KV_GRANTS["your-id"] to see which boards a player received.
